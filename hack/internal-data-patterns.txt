# Keep every pattern specific. A rule that fires on ordinary prose trains
# people to ignore this check, which is worse than not having it.
#

# environment — its domains, its network ranges, its service names — goes in
# hack/internal-data-patterns.local.txt, which is not in the repository:
# a list of the things you are hiding is itself worth hiding.
# Copy hack/internal-data-patterns.local.txt.example to start one.
